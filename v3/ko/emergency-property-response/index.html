Process

부동산 긴급 상황? 지금 전화하세요.

  1. 안전 확보

    유리, 물, 손상된 구조물에서 사람을 멀리하세요. 화재, 부상, 가스는 911에 신고하세요.

  2. IVO에 전화

    주소, 상황, 노출된 부분을 알려주세요. 작업팀과 도착 시간을 확정합니다.

  3. 임시 조치 후 영구 계획

    즉시 보드업 또는 보호 조치, 보험용 사진, 서면 수리 계획.

  4. 기록 및 마무리

    작업 전·중·후 사진, 승인, 준공 문서를 기록에 저장합니다.
