Process

物业紧急情况？立即致电。

  1. 确保区域安全

    让人员远离玻璃、积水和受损结构。如有火灾、受伤或燃气泄漏，请拨打 911。

  2. 致电 IVO

    告诉我们地址、发生了什么以及暴露情况。我们确认人员和到达时间。

  3. 先临时处理，再制定永久方案

    立即封板或防护，为保险公司拍照，并提供书面维修计划。

  4. 记录与交付

    施工前、中、后的照片、审批和竣工文件都保存在您的记录中。
